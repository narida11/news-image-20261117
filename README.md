A deterministic Python program that draws the world news of Tuesday, 17 November 2026 as a one-page newspaper in a single 1024x1024 PNG: a burning LPG tanker in the Strait of Hormuz, the Quad leaders summit in Manila, the Crimea Bridge strike, COP31 in Antalya, Wall Street and Nvidia, the Ebola outbreak in Congo, US storms, Voyager 1 nearing one light-day, and the day's football.

## Run it

pip install pillow, then run: python3 main.py

Running it writes /output/entry.png. No network access; the same bytes come out on every run.
